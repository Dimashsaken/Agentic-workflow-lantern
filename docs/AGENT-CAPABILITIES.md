# Agent file and tool capabilities

Generated by `python tools/azure-runner/tool_policy.py`. Do not hand-edit.

All roles can read repository files, their own run, and the product checkout, excluding conventional credential filenames and filesystem aliases. This is not a content secret scanner; all have validated read-only Git and execution-bound memory append. The product shell is a separate OS containment boundary.

| Role | Artifact write scope within its run | Product shell | Desktop exports |
|---|---|---|---|
| researcher | 00-story: `research.md`, `research.json`, `report.md` | no | no |
| story | 00-story: `story.md`, `story.json`, `report.md` | no | no |
| ui-ux | 01-ui-ux/ (host artifacts excluded) | no | design phase only |
| pre-coding | 02-pre-coding/ (host artifacts excluded) | no | no |
| coding | 03-coding/ (host artifacts excluded); each builder has its own subdirectory | auto mode only | no |
| reviewer | 03-coding: `report.md`, `review/review.json`, `review/round-*.md` | no | no |
| qa-dev | 04-qa-dev/ (host artifacts excluded) | no | no |
| post-coding | 05-post-coding/ (host artifacts excluded) | no | no |
| validator | 05-post-coding: `report.md`, `validation.md`, `validation.json` | no | no |
| security | 06-security/ (host artifacts excluded) | no | no |
| qa-staging | 07-qa-staging/ (host artifacts excluded) | no | no |
| debug | current debug stage/ (host artifacts excluded) | no | no |

Later roles append to shared reports. Coding file writes also obey the plan's product scope. Gate records, traces, manifests and coding handoffs are reserved for the harness. Text file tools cannot manufacture binary media evidence.
